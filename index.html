Panduan Edukatif & Kode Sumber

Bagaimana Cara Browser Menyimpan File?

LocalStorage hanya dapat menyimpan data dalam format String (teks biasa) dengan metode key-value.

PENTING: Anda tidak bisa langsung menyimpan object biner mentah seperti file .xlsx, .png, atau .pdf langsung ke LocalStorage. File tersebut wajib dikonversi atau diparsing terlebih dahulu!

Pendekatan Konversi File:

  • Parsing Data (JSON/CSV/Excel): File dibaca, diambil data tabular/strukturnya, diubah menjadi Array of Objects di JavaScript, kemudian diubah ke teks JSON dengan JSON.stringify() baru disimpan.
  • Encoding Biner (Gambar/PDF): File diubah menjadi string panjang berformat Base64 DataURL menggunakan API browser FileReader.readAsDataURL().

Batas Kapasitas LocalStorage:

Rata-rata browser membatasi penggunaan LocalStorage maksimal sebesar 5 MB per domain (origin). Menyimpan file gambar berukuran besar sangat tidak disarankan karena Base64 meningkatkan ukuran file sekitar 33% dan dapat memblokir kinerja render UI (Thread Synchronous).

IndexedDB: Solusi Penyimpanan Skala Besar

IndexedDB adalah database transaksional berbasis objek di browser untuk menyimpan data terstruktur dalam jumlah besar, termasuk objek biner (seperti gambar, file audio, file Excel, PDF) secara langsung sebagai Blob.

Kelebihan Utama IndexedDB dibanding LocalStorage:
  • Kapasitas Raksasa: Tidak terbatas pada 5MB. IndexedDB dapat memakai hingga 50% dari ruang disk kosong perangkat pengguna (ratusan Megabyte hingga Gigabyte).
  • Asinkronus (Non-Blocking): Operasi database berjalan asinkronus (event-driven), sehingga UI browser Anda tidak akan lag/hang saat membaca data besar.
  • Mendukung Data Biner Asli: Bisa menyimpan tipe data Blob, File, atau ArrayBuffer secara langsung tanpa konversi string Base64 yang memakan memori.
  • Fitur Query Canggih: Mendukung indeksasi data, transaksi penuh (rollback otomatis bila error), pencarian rentang kunci (key range queries), dan penanganan beberapa database.

Kapan Harus Beralih ke IndexedDB?

Ketika aplikasi web Anda memerlukan penyimpanan luring (*offline support*), mengelola data masal ribuan produk, menyimpan galeri foto buatan user lokal, atau ketika mengolah file Excel/PDF mentah di sisi klien.

Memproses File Excel (.xlsx / .xls)

File Excel adalah file biner terkompresi yang kompleks. Untuk membaca data di dalamnya di sisi klien (browser tanpa server), kita menggunakan pustaka open-source bernama SheetJS (XLSX).

1
Pilih File Excel

User mengunggah file .xlsx / .xls melalui elemen input file.

2
FileReader (ArrayBuffer)

Membaca file sebagai biner mentah: reader.readAsArrayBuffer(file).

3
SheetJS Parse Workbook

Memparse biner Excel menjadi objek workbook: XLSX.read(data, {type: 'array'}).

4
Konversi Sheet ke JSON

Mengambil data baris-kolom sheet tertentu menjadi Array JSON: XLSX.utils.sheet_to_json(sheet).

5
Simpan string JSON

Menyimpan data string ke memori lokal: localStorage.setItem(key, JSON.stringify(jsonData)).

Dengan cara ini, file Excel yang tadinya berformat biner beralih menjadi format data terstruktur JSON yang mudah dirender ke HTML.
